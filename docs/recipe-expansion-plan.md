# ATM10 8.3 配方与获取方式补全

目标：从锁定版本的官方文件扩展现有合成树，追踪到可采集、掉落或明确的特殊操作；未知步骤不伪装成基础材料。

沿用现有数据集 ID、所有旧物品身份和旧配方。原生数据按类型适配，保留条件、概率、副产物与来源。只读解析包内资源，不执行模组代码。KubeJS 的可解析移除规则优先排除原生配方；无法确定的修改须披露。中文和图标继续从同版资源生成。

- [x] 扫描官方服务端模组、原版客户端、KubeJS 数据与覆盖规则，建立可复现来源索引。
- [x] 测试并实现工作台、熔炼、锻造及关键模组机器适配；严格处理数量、组件、流体和化学品。
- [x] 递归解析材料标签，导入矿物/生物/战利品/特殊操作来源，构建可达依赖闭包和中断报告。
- [x] 为已解析路线选择可终止的默认路径，扩展树深度，展示获取说明和来源；不把概率产出记为确定制作。
- [x] 扩充中文与资源图标，验证旧存档、数量分配、标签消耗、配方边界与真实图标加载。
- [x] 独立审查、生产构建与浏览器验收；发布状态以 Sites 版本与部署记录为准。

执行记录：静态扩展与游戏文件导入已实现。原有 556 条配方及 1,040 个身份的指纹检查保持一致；原始配方记录未改写，复用物品在规划层处理。当前还有 3124 个可达标识缺少已支持配方/来源（包含部分设备类型及动态注册条目），以及 104 个未解析脚本表达式，已完整列入报告。此状态不等于全量游戏运行时核验；未解决节点继续显示待核验。
