# 导入 Minecraft 本地存档进度

导入功能只在浏览器中读取你手动选择的文件；不会上传存档、连接服务器或读取游戏目录。支持 Minecraft Java 1.21.1 的原始 NBT 和 gzip 压缩 NBT。

可选择以下其中一个文件：

- 单人世界：`.minecraft/saves/<世界名称>/level.dat`
- 多人或指定玩家数据：`.minecraft/saves/<世界名称>/playerdata/<UUID>.dat`

先完全关闭游戏，再复制文件到其他位置后选择副本。这样可避免游戏正在写入 `level.dat` 或玩家数据，造成导入到一半的文件损坏。

导入会读取当前玩家背包、末影箱，以及物品内的原版 `minecraft:container`（例如潜影盒）内容；同一个槽位列表中的每一叠物品都会分别计数。它按物品 ID 和已收录的数据组件匹配，因此带附魔、流体等特殊物品不会被当成普通物品或另一种特殊变体。

这是当前持有量快照，不会推测已经消耗的材料、曾经完成的合成或外部仓储内容。模组背包、抽屉、仓库等可能显示为提示但不会展开读取；未收录或无法精确匹配的物品会保留为未识别项供检查。

为保护浏览器，原文件限制为 8 MB，gzip 解压后限制为 32 MB；损坏、截断或过深的 NBT 文件会被拒绝。
