# ATM 星图 · 首版设计

用户已批准的范围：ATM10 8.3 官方数据验证、中心发散合成树、配方详情、数量进度、多目标本地保存、分享快照、静态网站。

## 数据边界

固定 CurseForge file 9190157，下载文件 SHA-256 为 24440fb355de69b28af6ff18556b5d0598bb93570b2b745552cdb1bcb5448c8f。manifest 必须是 All the Mods 10 / 8.3 / Minecraft 1.21.1 / neoforge-21.1.259。优先解析发布包内脚本，保留文件路径、行号和哈希。仅做静态 AST 读取，不执行第三方脚本。配方 ID 在源文件未显式指定时使用带来源的本地 ID，绝不冒充运行时 ID。数据组件作为物品身份一部分。未解析获取方式显示为待核验，不冒充天然资源。公开界面明确说明“发布包脚本核对，未运行游戏核验”。

## 应用

React + TypeScript + Vite + React Flow。中文主界面，深蓝灰画布、薄荷绿操作、紫金色星体，三栏布局。中心目标第一圈展示直接原料，按需展开径向分支。物品详情展示来源模组、配方网格/机器、产量、材料数量、能耗/流体、来源证据。不同配方、标签和备选材料支持显式选择。

## 进度

每个项目独立使用 itemKey → 已拥有数量，不是全局勾选布尔值。完整组件 key 区分普通与觉醒物品。展开路径表示需求实例，数量从同一项目的物品池按确定顺序分配，父产物已拥有的数量替代其对应子需求，避免双计数。整批制作向上取整并保留余量提示。工具/零消耗催化剂只要求可用，不按每批消耗。循环与深度限制有明确终止状态。总览直接材料就绪度与最终制成状态分开。完成原料不自动宣称已制成父物品。

## 保存与分享

IndexedDB 保存项目、当前项目、路线选择、备注、展开路径。保存失败保留内存状态并明确反馈。JSON 文件提供导入/导出；数据校验拒绝危险或不兼容内容。压缩 URL fragment 创建只读快照，打开后须复制为个人项目才能编辑。长度过大引导导出文件。分享只包含当前项目，不包含其他存档。快照绑定数据集版本。首次打开为空进度的 ATM 之星项目，无虚构完成记录。

## 验证

核心测试覆盖批量产出、重复材料分配、组件差异、催化剂、循环、父物品短路、路线选择、非法导入、快照隔离和 IndexedDB 读写。数据验证直接比对发布包来源。浏览器验收展开、配方详情、数量修改、新建/切换目标、刷新恢复、只读分享和复制。构建成功后静态发布，保留新 Site 默认访问范围。
