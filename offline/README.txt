ATM 星图 · ATM10 8.3 离线版（程序版本见 release.json）
适用：Windows 10/11，x64（64 位 Intel/AMD），现代 Edge 或 Chrome 浏览器。

【开始使用】
1. 把整个 ZIP 完整解压到任意普通文件夹。不要直接在压缩软件中运行 CMD。
2. 双击“启动ATM星图.cmd”（或英文名 Start.cmd）。无需安装 Node.js/Python，无需管理员权限，无需 VPN 或联网。
3. 浏览器会自动打开 http://127.0.0.1:43183 。若未自动打开，请复制该地址到 Edge/Chrome。
4. 保持启动窗口打开。结束时在该窗口按 Ctrl+C，或关闭该窗口；下次仍双击启动。
5. 页面上的目标、物品数量、配方选择、三种布局、JSON 导入导出和游戏 .dat 文件识别可离线使用。

【进度保存】
进度自动保存在“当前浏览器 + http://127.0.0.1:43183”的 IndexedDB 中，不保存在本程序文件夹。
关闭启动窗口不会删除进度。解压到其他文件夹、更新程序包后，使用同一浏览器和同一地址可以继续读取。
清除网站数据、浏览器隐私/无痕模式、换浏览器或换电脑可能无法读取原进度，请定期用“导出存档”备份 JSON。
不要把地址换成 localhost，也不要更改端口；它们是不同的浏览器存储位置。

【从在线版迁移】
在原网站点击左侧“导出存档”，保存 JSON；启动离线版后点击“导入”并选择 JSON。
导入追加独立副本，不覆盖原有目标。在线版与离线版不会自动同步。

【分享给朋友】
把完整 ZIP 发给朋友，对方解压后按同样步骤启动。
如需分享你的进度：在“分享进度”中导出此目标 JSON，或左侧导出全部存档，然后把 JSON 发给朋友导入。
127.0.0.1 仅指向各自电脑，不是别人可以直接访问你电脑的公网链接。
包内不包含制作方或其他用户的浏览器进度。

【识别游戏存档】
选择“从游戏存档识别进度”，按页面说明选择 level.dat 或 playerdata/<UUID>.dat。
文件在浏览器本地解析，预览后追加目标；不上传，也不修改 Minecraft 文件。
仅识别这些文件实际包含的背包、末影箱和支持的内嵌容器；不代表识别整个世界的箱子或 AE/RS 存储网络。

【重复启动、端口与升级】
同一版本重复启动会复用已经运行的服务并打开页面。
如果提示端口被旧版本占用，请先关闭旧的 ATM 星图启动窗口，再启动新版。不要同时运行不同版本。
若被其他程序占用，请先关闭占用程序。为保护进度，启动器不会随机换端口。
升级前先导出进度备份，关闭旧启动窗口，再将新 ZIP 解压到新文件夹并启动。
该程序只监听 127.0.0.1，不需要对局域网开放访问。

【版本、完整性与边界】
release.json 记录包版本、ATM10 数据版本、构建标识和官方 Node.js 运行环境来源。
files.sha256.json 记录包内文件 SHA-256；ZIP 旁的 .sha256 文件用于核对整个压缩包。
配方仍有动态/条件/概率等静态解析边界，缺失译名和特殊图标保留现有说明；离线版不新增未经核实的配方。
“数据来源”的外部网站链接需要联网，日常追踪和存档功能无需联网。
前端和 Node.js 许可证、物品资源来源见 licenses/ 和“第三方资源说明.txt”。
